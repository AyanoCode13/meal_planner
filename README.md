# Meal Planner

A Flutter, cross-platform meal planner app for IOS and Android that allows the user to handle food and recipe management, notifies the user on expiring product and suggests meals and allows the user based on ingredients in the storage , dietary preferences and monthly budget.

# Generate Files
    dart run build_runner watch --delete-conflicting-outputs
# Test
    - Product: flutter test test/product --reporter expanded
    - Recipe: flutter test test/recipe --reporter expanded
